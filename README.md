## 📍 The Problem

> **260 million students in India** navigate their academic lives through WhatsApp forwards, blurry notice board photos, PDFs nobody reads, and institutional bureaucracy that wasn't designed for the smartphone generation.

The average Indian college student juggles:

| Pain Point | Reality |
|:---|:---|
| **Notice Chaos** | 15+ WhatsApp groups forwarding the same circular in different crops and rotations |
| **Deadline Anxiety** | Fee deadlines buried in 3-page PDF circulars written in legalese |
| **Attendance Gambling** | Mental math before every bunk — "Can I afford to skip today?" |
| **Scholarship Blindness** | ₹10,000+ Cr in scholarships go unclaimed because students don't know they qualify |
| **Information Overload** | 50+ notices per semester, zero structured way to process them |

**The result?** Missed deadlines. Lost scholarships. Preventable academic anxiety.

**ScholarSync exists to end this.**

## 🚀 Core Features

### 🔬 AI Notice Scanner — *The Intelligence Engine*

The crown jewel. Students upload **any** academic document — a blurry WhatsApp screenshot, a dense PDF circular, a hastily photographed notice board — and the AI engine transforms it into structured, actionable intelligence.

**What the AI extracts (19 data fields):**

| Category | Extracted Data |
|:---|:---|
| **Core** | Title, Summary, Student-Friendly Explanation |
| **Temporal** | Deadlines (ISO 8601), Event Dates, Timeline |
| **Financial** | Fee Amounts, Fee Breakdown (mandatory/optional/fine/refundable) |
| **Action** | Required Actions (chronological), Required Documents |
| **Classification** | Priority (4-tier), Category (10 types), Risk Level, Emotional Context |
| **Metadata** | Department, Issuing Authority, Notice Type |
| **AI Output** | Task Cards, 5-Day Study Plan, Personalized Recommendations |

**Student-Friendly Rewriting** — The AI doesn't just extract; it *translates*:
> *Before:* "Students failing to remit the examination fee within the stipulated period shall be debarred from appearing in the said examination."
>
> *After:* "Hey, you need to pay your exam fee before Friday, or your hall ticket might get blocked. Here's what to do..."

**Supported inputs:** PDF, PNG, JPG, drag-and-drop, pasted text, mobile camera uploads.

---

### 📋 AI-Generated TODO System

When the AI generates a **5-Day Study Plan** from a scanned notice, students can convert it into a fully interactive, editable TODO system with one click.

- **Spatial drag-and-drop** task management
- **AI-generated** and **manual** task creation
- **Per-day breakdown** with focus areas and actionable steps
- **Real-time sync** to Firestore — tasks persist across devices
- **Progress tracking** with completion animations

---

### 📊 Intelligent Dashboard

A spatial, widget-based command center that adapts to what matters *right now*:

- **Urgent Deadlines** — Tasks due within 48 hours, with red glow severity indicators
- **Today's Priorities** — AI-sorted by urgency, category, and deadline proximity
- **Attendance Widget** — Live SVG ring showing aggregate attendance health
- **Upcoming Timeline** — Visual timeline of approaching deadlines
- **Scholarship Alerts** — Matched scholarships with nearest deadlines
- **AI Insights** — Contextual tips and warnings generated from your data

---

### 🎓 Scholarship Matcher — *Smart Discovery Engine*

A recommendation system that **actively finds** scholarships students qualify for.

- **Real Indian scholarships** — NSP, PM-YASASVI, AICTE Pragati, state-specific grants
- **Profile-based matching** — Scores match percentage based on state, course, category, gender, and income
- **Real-time bookmarking** — Save and track applications per user
- **Urgency indicators** — Visual deadline countdowns with color-coded severity
- **Direct apply links** — One-tap to official application portals

---

### 📈 Attendance Predictor

End the mental math. Know exactly where you stand.

- **Per-subject tracking** with attended/total class counts
- **Risk classification** — Safe (>80%), Warning (75–80%), Danger (<75%)
- **Safe bunk calculator** — "You can skip 3 more classes and stay above 75%"
- **Visual progress rings** with animated mount transitions
- **Firestore persistence** — data survives app restarts

---

### 🧮 GPA Predictor

Smart SGPA/CGPA calculator with forward projection:

- **Add subjects** with credits and expected grades
- **SGPA computation** with Indian grading system
- **Target CGPA tracker** — "You need X.XX this semester to reach your goal"
- **Multi-semester planning** with cumulative projections

---

### 🫀 Emergency Mode — *"I'm Overwhelmed"*

**A feature no other student app has.** When academic pressure peaks, one button transforms the entire interface:

- **Strips all non-critical information** — only urgent deadlines and today's priorities remain
- **Calming visual overlay** — indigo-tinted, reduced motion, softer contrast
- **Focus audio player** — ambient rain, lo-fi study beats, forest soundscapes
- **Reassurance banner** — *"Focus Mode Active — Only critical items are visible. You've got this. 💙"*

This isn't a gimmick. It's an empathy-driven design decision that acknowledges **student mental health is a product feature**.

```
├──────────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────────┤
│                      PERSISTENCE LAYER                       │
│                                                              │
│  Firebase Auth (Google, Email/Password)                      │
│  Firestore (Real-time sync, user-scoped collections)         │
│                                                              │
│  users/{uid}/                                                │
│  ├── tasks/         → Extracted action items                 │

│  ├── todoLists/     → AI & manual todo collections           │
│  ├── bookmarks/     → Saved scholarships                     │
│  └── profile        → User profile & preferences            │
│                                                              │
│  scholarships/      → Global scholarship database            │
└──────────────────────────────────────────────────────────────┘
```

### Performance Engineering

| Technique | Implementation |
|:---|:---|
| `React.memo` | Memoized cards, filters, and list items to prevent re-render cascades |
| `useTransition` | Non-blocking search/filter updates for fluid UI during heavy state changes |
| `useCallback` | Stable function references across re-renders for memoized child components |
| Defensive data validation | Every Firestore payload hardened against `undefined` values |
| Optimistic UI | Instant feedback on user actions, synced to backend asynchronously |
| Code splitting | Route-based splitting via Next.js App Router dynamic imports |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- Firebase project with Firestore + Authentication enabled
- Gemini API key

### 1. Clone & Install

```bash
git clone https://github.com/your-org/scholarsync.git
cd scholarsync
npm install
```

### 2. Configure Environment

Create `.env.local` in the project root:

```env
# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

# Gemini AI
GEMINI_API_KEY=your_gemini_api_key
```

### 3. Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — the landing page loads instantly.

### 4. Build for Production

```bash
npm run build
npm start
```

## 💎 Design Philosophy

### Glassmorphism + Spatial UI
Every surface in ScholarSync uses subtle translucency, backdrop blur, and layered depth to create a premium, spatial feel. Cards tilt on hover with 3D transforms. Backgrounds float with animated particles.

### Dark-First, Light-Ready
The interface is designed dark-first for reduced eye strain during late-night study sessions, with full light mode support.

### Motion as Meaning
Animations aren't decorative — they communicate state. Spring physics on page transitions. Stagger reveals on data load. Pulse effects on urgency. Every motion has intent.

### Empathy-Driven
Emergency Mode isn't just a feature. It's a statement: **we understand that academic pressure is real, and technology should help, not add to it.**
